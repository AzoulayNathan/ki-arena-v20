# KI ARENA V19.2

Extraire le ZIP complet. Double-cliquer JOUER_KI_ARENA_V19.html ou LANCER_SUR_PC_WINDOWS.bat. Le nom HTML et le dossier restent stables pour limiter les changements de chemin des sauvegardes locales.

Alternative avec Node 18+ : `npm start`, puis http://127.0.0.1:4173. `npm test` vérifie les suites. `npm run build:offline` reconstruit le HTML. Lire STATUS_V192.md et RAPPORT_QA_V192.md pour les limites vérifiées.

Nouveau : statistiques de cartes ATQ / VIT / PV, guide de départ, préparation et combat gauche/droite, FX procéduraux par attaque/univers, quatre pochettes de packs illustrées, révélation et inspection, catalogue grisé pour les cartes non possédées.

Un pack de cinq par run après au moins un combat résolu. Plus de cumul ni d'historique par étage dans la nouvelle interface. Dans Collection, cliquer Ouvrir mes packs ; choisir un pack disponible ; cliquer les cartes pour les retourner puis les agrandir. Tout révéler est disponible. Cliquer à côté ou Échap ferme la fenêtre. Revoir le dernier pack rejoue le même résultat, sans nouvelle carte.

Avant de remplacer une installation, exporter la run et le Panthéon par les réglages existants ; conserver le dossier précédent pour rollback. La collection est stockée localement dans le navigateur. Un autre navigateur ou un autre chemin de fichier peut avoir un stockage distinct ; aucun cloud n'est ajouté.

Le classement manuel n'est pas encore intégré faute de fichier validé. Les portraits hérités ne sont pas tous finis. Les contrôles Windows réels restent à faire. Le deuxième solo ouvert est décrit dans IDEES_EXPEDITION_V192.md.
