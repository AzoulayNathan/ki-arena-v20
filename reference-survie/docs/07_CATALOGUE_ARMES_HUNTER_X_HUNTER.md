# Catalogue d'équipements — Hunter × Hunter

**55 entrées de travail**, dont 38 disponibles dans le pool général d'équipement. Le **draft initial de trois armes** ne tire que dans les lignes `classe=arme` et `compatible_draft=oui` (26 références). Les statistiques sont des créations de game design et **ne correspondent pas à des valeurs officielles**.

Le catalogue couvre les objets identifiés, des types d'armes courants des arcs et les équipements remarquables ; il n'est **pas garanti exhaustif** pour toutes les armes anonymes visibles dans toutes les cases du manga. Le champ `source` et le statut de preuve sont essentiels avant publication.

### Portée canonique
- Objet nommé / attesté : 29
- Nen personnel : 16
- Catégorie attestée : 7
- Extrapolation éditoriale : 2
- Exclu du draft : 1

**Important :** les armes corporelles et les effets de Nen ne sont pas des objets physiquement transférables. Les équipements personnels de Nen sont consignés mais exclus du pool générique. Les objets issus de jeux, films, GT ou Daima ne doivent pas être ajoutés automatiquement à Dragon Ball.

## Équilibrage / intégration
Les colonnes `attaque_bonus_pct`, `armure_bouclier_pct`, `soin_pct` et `pioche_supplementaire` sont **des paramètres proposés**. `cout_action_equipement=0` signifie pose gratuite ; `=1` utilise une action d'équipement du round sans constituer un système de mana. `utilisations_par_combat=1` limite l'activation de l'effet ; la carte retourne dans le deck au prochain combat si son propriétaire survit.

Les variantes de même famille (« fusil », « armure Saiyan », etc.) ne sont pas de nouveaux artefacts canoniques nommés : elles élargissent seulement le pool visuel et doivent être regroupées si elles deviennent redondantes. Les sources Fandom sont des encyclopédies communautaires à recouper avec l'œuvre avant d'annoncer une fidélité parfaite.
