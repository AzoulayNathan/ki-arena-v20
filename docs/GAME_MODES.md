# KI ARENA V3 — Modes jouables

Les jeux libres utilisent les **300 cartes** du catalogue, indépendamment de la collection personnelle.

| Mode | Principe | Options |
|---|---|---|
| Team ×5 | Deux équipes tirées au hasard ou construites manuellement, puis duel automatique | 1/3/5 cartes, saga, rareté, canon/équilibré, vitesse |
| Draft à budget | Trois propositions par emplacement, budget limité ; mode CPU ou 2 joueurs locaux | Budget 120 KI par emplacement, relance unique, taille de team, filtres |
| Draft aveugle | Choix entre cartes masquées, révélation après cinq tours, combat | CPU ou 2 joueurs locaux, 1/3/5 emplacements |
| Tournoi | Bracket automatique de 8 ou 16 équipes aléatoires, champion final | Saga, taille de team, style de puissance |
| Blind ranking | Cinq cartes à classer sans connaître les suivantes | Tirage filtré par saga/rareté |
| Plus ou moins | Devine qui possède le plus d'ATQ/PV/VIT, puis dévoile les statistiques | Série et rareté maximales |
| **Survie infinie** | **Roguelike** : cinq cartes possédées, zones à embranchements, boss, objets, reliques, recrues, packs de fin de run | Réglage équilibré, difficulté progressive, route aléatoire, réserve |

Les combats sont automatiques ; une attaque normale par combattant vivant et par round, déclenchements ponctuels des effets. Animation avec vitesse ×1/×2/×4/×8 et journal d'événements. Voir `ROGUELIKE_V3.md` pour les règles complètes.

> Le multijoueur en ligne n'est pas encore présent : uniquement local avec CPU ou deux joueurs sur le même appareil dans les deux drafts. Les applications natives ne sont pas compilées.
