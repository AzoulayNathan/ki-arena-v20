3. Capacités : valider personnage par personnage les adaptations éditoriales, leurs contre-jeux et leur équilibrage. Les profils 17/18 sont des signatures de paramètres, pas une preuve de diversité stratégique exhaustive.

5. Retrouver reference-survie pour exécuter réellement les douze tests Python d’origine ; ne pas écrire des tests de remplacement pour masquer l’absence.
6. Effectuer une partie manuelle complète de chaque mini-jeu, chaque phase et chaque état de reprise. Les tests moteur existants passent, mais ne valent pas cette recette.
