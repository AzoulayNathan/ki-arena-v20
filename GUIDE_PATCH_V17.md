# Patch V16 → V17

La version complète est recommandée. Extraire le patch, puis exécuter avec Python 3 :

`python APPLIQUER_PATCH.py "CHEMIN_DU_PROJET_V16"`

Les fichiers runtime de la V16 sont vérifiés avant toute modification. Les fichiers remplacés sont sauvegardés, puis le HTML V17 est reconstruit. Les sauvegardes de navigateur ne sont pas supprimées. Une nouvelle aventure applique le draft corrigé ; les anciennes runs conservent leur version.

Une base modifiée est refusée. Le patch reconstruit le même HTML que le projet complet. Pour revenir à la V16, utiliser son archive originale dans un dossier séparé.

L’équilibrage global du départ affaibli reste non validé ; voir STATUS_V17.md.
